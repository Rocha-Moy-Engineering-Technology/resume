# Contractor Site

- `src/` — Svelte components, pure logic, state controllers, types/ports, browser adapters, styles, assets, and unit tests.
- `public/` — Verbatim static assets, including the downloadable resume Portable Document Format (PDF) file and favicon.
- `tests/` — Headless browser integration, end-to-end, smoke, and screenshot-gallery tooling.
- `evidence_gallery/` — The latest verification index, linking to captures in the agent-root temporary folder.
- `docs/` — Design/reference notes and earlier owner-approved screenshots.
- `pic.png` — The authoritative full-resolution profile photograph.
- `index.html` — Browser document template and pre-paint theme bootstrap.
- `package.json` and `package-lock.json` — Project commands and pinned JavaScript dependencies.
- `vite.config.ts` — Build transforms, unit-test configuration, and coverage gates.
- `playwright.config.ts` — Isolated headless browser projects and their preview server.
- `eslint.config.js` — Source lint and complexity rules.
- `tsconfig.json` and `tsconfig.node.json` — TypeScript project settings.
- `.gitignore` — Generated and machine-local output exclusions.
- `.prettierrc` and `.prettierignore` — Formatting settings and exclusions.
